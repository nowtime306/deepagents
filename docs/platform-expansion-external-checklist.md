# 本轮外部接入与后续验收清单

2026-11-02。本机协议替身、受限容器与页面测试不等于外部真实效果。按用户此前要求，真实外部模型联调继续跳过；接入完成后再验，不把这些项目填成已通过。原有服务配置参见[原接入清单](integration-checklist.md)，本文件补本轮扩展。

1. 企业登录：在设置中配置真实OIDC issuer、client ID和secret，登记平台回调地址；提供可用于测试的最小权限账号及允许新建/绑定策略。随后验证真实发现、登录、退出/来源停用、显式绑定及MFA，不凭邮箱自动合并账号。本机签名IdP通过不能替代企业SSO验收。
2. 邮件/短信：配置真实SMTP或签名短信Webhook，并指定用户本人可接收的测试地址/号码。真实发送需有明确测试授权；之后验证送达、限流、令牌单次使用和改密会话撤销。不在聊天或报告中提交密码、验证码、TOTP种子和恢复码。
3. 业务MCP：提供实际只读/写入工具服务、允许域、工具schema和测试账号；OAuth另需预注册client、资源及scope。随后验证真实发现、授权刷新/撤销、Work写审批和结果未知不重放，不能用本地SDK替身证明业务服务可用。
4. 外部ACP Agent：提供已批准的容器镜像/命令和必要的第三方Agent登录环境；测试会话、更新、取消、文件/终端权限及隔离环境销毁。不能在宿主执行用户任意命令或自动下载安装未批准包。
5. 图搜图/视频帧检索：在模型管理中配置真实支持图片输入的多模态向量模型，给知识库绑定索引，并提供有标注的样图/短视频。之后验证实际相关性、维度/修订固定、来源时间和计量；帧检索不代表音轨或完整时序理解。
6. 各模型真实协议：按模型用途、服务商、真实协议逐项验；四态矩阵只表示工程路径。供应商未联调不标“真实可用”，不支持协议继续明确拒绝。独立语音合成、图片理解导航仍按用户要求隐藏，保留鉴权API和已批准入口。
7. 价格/账单：管理员录入真实合同单价、计费单位和币种，导入脱敏且有调用ID/账期的供应商账单；随后核对实际秒数/张数/Token、迟到费用及差异。未报告数量保持未知，人工确认留下审计，不自动换汇或改写已确认历史。
8. 真实知识质量：提供至少50道实际业务题，包含有答案/无答案类别、来源证据、模型实际回答和人工引用/拒答标签。验证Recall@10、引用正确率及拒答各自分母与发布门禁。受控本机fixture和合成题不代表真实业务达标。
9. 第二主机/故障域：提供目标主机及存储/网络条件后，还需按实际拓扑落地共享附件、向量单写服务/路由、稳定入口与远端节点部署，再验证跨机接管、存储围栏和恢复。这部分包含后续工程及环境联调，不能说仅填凭据即可成为生产多机HA；当前已交付的单机profile、同机主备/维护围栏探针与健康负载报告不能替代物理高可用、业务容量或灾备认证。

本机监测栈不是外部待接入项：本轮已实际启动，授权抓取up、规则加载、Grafana强制登录与中文14面板/JS错误0验证通过；详见[扩展交付记录](platform-expansion-acceptance-2026-11-02.md)。后续改动仍需相应检查，不以缺少外部模型凭证为由跳过本机运维验收。

接入时仅将密钥填写平台相应配置页面；模型/身份/渠道/MCP凭据由服务端加密保存。验收报告只保存状态、编号、脱敏摘要和计量结果，禁止导出明文凭据或用户正文。
