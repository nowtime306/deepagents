## 按需求核对

- **RDC-01 智能体与自动任务**：资源 ID 引用当前兼容模型；发布版、自动任务、调度和 Ask/Work 清理通用修订阻断。删除、停用、用途/协议和实际能力不足仍拒绝。工具能力未知不会自动当作支持。隔离 API、调度、Ask/Work 回归已有证据；真实供应商模型效果跳过。
- **RDC-02 团队**：成员业务版本继续固定，成员模型维护不级联要求重发；运行追溯区分角色、成员版本和实际模型。团队采用受控 ToolModel 真委派，快照和授权边界已有后端用例；真实 Work 团队环境未计入 401 项 QA 的通过范围，也不是新页面体验证明。
- **RDC-03 工作流**：历史发布/回退、只读、持久执行、外部 API、Ask/Work 及子流程采用资源解耦规则；已绑定业务版本不随当前发布指针改变。工作流与历史版本后端回归通过；画布实际错误定位及返回状态仍待页面验收。
- **RDC-04 运行一致性及恢复**：排队准入不等于配置确定，实际执行开始及首次使用固定；同阶段普通维护保持快照，新运行采用新配置。冷恢复更换接收目标进入待确认，确认内容按摘要和阶段做并发检查，新增执行阶段。模型安全恢复沿用原检查点；有旧审批、未知副作用、路由或非模型恢复依赖时明确转人工核对，不声称全部可自动恢复。401 项 QA 的冷恢复采用清理进程缓存及 HTTP 阶段确认；真实检查点消费者恢复另见 Coding 专项，即便新消费者验证通过也不等于实际重启宿主进程。
- **RDC-05 修改记录**：模型、MCP、路由、知识/记忆设置、仓库和通知保留成功变更、可信操作者、来源、类别及脱敏前后值；隐式默认切换共享变更标识。并发失败不产生成功历史，删除后按原归属可查，旧数据只建立明确基线。真实 PostgreSQL 及 HTTP 测试覆盖列表/详情关联一致、同一配置修订关联 501 条运行时每条历史独立限额、跨账号隔离和脱敏。
- **RDC-06 排查入口**：运行详情有实际资源、业务版本、阶段、已解析/已使用、调用关联及当前差异；子流程定位共享父作用域。旧信息缺失不以当前配置补造。API 与多角色/多模型追溯通过；agent/memory/knowledge 当前投影的小改仅静态复核，未补齐专门三类 HTTP 序列化回归；页面跳转与返回仍未验。
- **RDC-07 路由**：实际开始解析当前策略，阶段内固定候选、原因和实际模型；同一运行已冻结模型不会悄悄切换。接收目标、候选、授权变化仍检查同意范围；普通名称/凭据维护不误判新增接收方。启动边界、授权和模型接收方维护回归通过；原作者参与的部分不冒称全部独立验收。
- **RDC-08 向量兼容**：文本、记忆、图片和视频按实际模型身份、协议、服务目标、预处理与维度判断，普通维护不误失效，同维不同模型不混查。地址迁移只接受管理员对明确目标的兼容确认，保留证据摘要；这不是系统自动证明供应商输出等价。旧未知/不兼容索引明确降级或要求核对，视频跨帧固定配置由受控解码/模型替身验证。
- **RDC-09 评测**：历史证据保留，效果相关指纹区分普通维护与行为/文档变化；严格门禁按实际效果适用性判断。实验阶段固定数据和检索配置，相关回归通过，真实检索效果仍待用户接入模型后验证。
- **RDC-10 工具及技能**：当前内容首次解析后固定，审批绑定实际目标、参数、脚本/路径与接口。展示注释维护不误伤，真实 Schema、只读性、授权或目标变化仍拒绝。HTTP 每次真实调用前再次检查撤权；BrowserSkill 审批展示冻结轨迹。接口比较保留 JSON 布尔与数字差异，不删除真实名为 description/title 的参数。受控反例与复审关闭；真实 Coding/stdio/ACP 补测单列，不以函数级进程替身冒充子进程集成。
- **RDC-11 仓库**：名称/同身份凭据维护不代替仓库身份、固定提交、子目录、分支、成果和推送审批检查。Git 对象、原生临时仓库与受控远端协议回归通过；真实 GitHub 业务推送/PR 效果未联调。
- **RDC-12 通知**：固定原接收目标及消息，同目标可用最新凭据；目标变更暂停，确认重投建立新记录并保留 retry_of。确认目标并发变化拒绝，未知结果不自动重发。随机本机接收器和 HTTP 权限反例通过；不是第三方收件验证。
- **RDC-13 一致性/权限**：保存 CAS、启停、撤权、版本下线、取消、租约、真实接口和审批内容检查保留；运行、私有资源和历史按原账号归属。082～084 实际旧库升级测试验证旧执行证据隔离、检查点/审批/凭据/文件保留及 SQL 阶段失败回滚，没有修改生产库。
- **RDC-14 中文交互**：既有资源/运行详情增加中文历史、差异与恢复入口，通知只读权限无写操作，模型全局管理历史仅管理员可达。前端类型、定向 lint、隔离生产构建通过；窄屏、键盘、加载/错误、未保存状态、节点/成员定位与返回路径没有实际页面验收，仍属发布门槛。
