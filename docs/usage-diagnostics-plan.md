## 设计取舍
- 先完善已有账本和诊断入口；不在这一批引入遥测数据库或外部监控服务。
- 时间是本平台观察的请求耗时；首次流式输出不是服务商内部推理计时。
- 缓存/推理明细不意味着计价已覆盖缓存折扣；当前费用继续沿用管理员输入/输出统一单价。精确 tokenizer、缓存独立价格、金额预扣、持久 Ask 调度和账号改密仍单独跟踪。
- 联网授权不等于实际执行搜索。应用搜索以工具事件为证据；OpenAI/Responses 服务端搜索没有独立应用事件时明确写“未独立采集”，不称没有搜索或已经搜索。
- Ask 新运行保存模式预算快照。历史记录不反填不存在的配置和用量。
