- 浏览器对既定测试页面的拒绝不由API脚本、CDP或抓取HTML绕过；本套脚本不承担UI验收。
- 旧预检目标仅凭真实进程退出、无连接/活动/未知资源及远端namespace为空等证据回收。启动失败的回执必须明确来源，不能伪造正常退出。
