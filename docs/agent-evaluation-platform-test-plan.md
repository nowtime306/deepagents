# Agent评测平台接入测试用例

依据AE-01～24及`agent-evaluation-platform-development.md`。代码审查通过后再执行测试；作者检查、独立工程、真实数据库、实际业务、页面和部署分别验收。状态以`agent-evaluation-platform-qa.md`及原始收据为准，本篇不是通过报告。

## 环境与数据

只使用本次随机后缀`_test`数据库和独立数据目录；生产账号、知识库、原会话、加密密钥和既有测试现场不覆盖。DeepEval独立Python环境，外部供应商及Confident上传保持未测试。测试账号与权限在隔离库中创建；测试报告不保存Cookie、明文密码、连接串或供应商凭据。仅回收登记的精确自有资源。

## 数据集与发布

- EP-01：无登录访问被拒；只有evaluation.read的账号可读本人数据，但不能新增、编辑或发布。管理员访问另一个账号私有ID同样404。
- EP-02：导入合法声明，返回规范定义/摘要；重复case ID、未知验证器/版本、非法参数、未知字段和非有限数值422，且无执行副作用。未验证fixture明确列入未就绪，不以结构通过宣称可执行。
- EP-03：新建后重开详情，名称、说明、定义和修订一致。只改名称仍保留原说明；页面关闭保护覆盖名称、定义、预算、批次及对比配置。
- EP-04：两客户端编辑同一草稿，只有匹配CAS的一次成功；旧修订409。发布快照不可变，后续草稿编辑不影响v1，重复发布相同内容不悄悄换版本。
- EP-05：任务定义数量与独立业务目标审核分开；达到20/100个ID不自动认为覆盖完成。预览、发布、准入页面都保留未测项。

## 批次、样本与预算

- EP-06：默认可信A验收或真实驱动缺失，POST runs为503且批次/样本新增0。validate_definition仅literal True放行，空对象、BLOCKED对象、字符串、整数1不算验证通过。
- EP-07：工程模式只允许一次，效果模式三次及额外前提单独检查；重复不是新增不同任务。创建前从所选已发布版本读取任务数，不能使用已变动草稿数替代旧版。
- EP-08：父总时长/调用/Token/沙箱预算低于所选任务保守预约时拒绝，不自动放大。未知费用/用量不填零；实际使用与预算分开展示。
- EP-09：同owner、同request_id及相同参数仅创建一个批次；不同参数409。并发提交仍唯一，事务中途失败不留下半套样本。丢响应不自动新POST或换request ID。
- EP-10：排队、运行、取消中、已完成、失败、待核验分别展示，COMPLETED不推PASS。QUEUED可取消；取消带真实revision，终态重复请求不追加效果。
- EP-11：只领取单个全局目标、租约过期和旧租约写入被拒；已开始派发后失联保留待核验，不自动重放。每次新效果前检查撤权、取消、维护与预算。
- EP-12：样本事实/指标/环境/回收/用量分别记录。缺原证据、未知效果或评分异常不PASS；事实失败不被高语义分豁免。
- EP-13：样本超过100条可分页；自动刷新保留已加载窗口，旧请求不能覆盖新数据，切换/卸载取消订阅。列表与详情仅GET轮询，不给全系统新增SSE。

## 报告、比较与改进

- EP-14：JSON/JUnit/中文报告同源同摘要、归属和执行快照正确；缺报告、摘要变更、来源不完整或未经脱敏时禁止下载。无前端报告上传或任意宿主路径读取接口。
- EP-15：比较必须逐case/repeat完整对齐；repeats=3但仅repeat1、重复样本、null身份或非法摘要不能输出可信提升。仅允许预定变化轴，其余漂移明确不可比较。
- EP-16：W01负控制的原任务/门禁FAIL必须保留；A验收出版单独核对负控制预期与独立事实，不改原报告为PASS，也不拿客户端expected字段任意豁免失败。
- EP-17：人工复核必须带真实样本revision、身份、理由和规则版本；只追加记录，不覆盖原facts/metrics/gate。旧修订冲突和无权限拒绝。
- EP-18：改进候选必须有明确授权及人工脱敏确认。Bearer/Basic等完整认证值、中文紧邻secret和备注同样脱敏；仅存脱敏材料。正则初筛不保证无密，仍需人工核对；批准候选不自动执行或修改已发布集合。

## 实际页面与上线

- EP-19：在已获工具实际访问权限的独立测试站，用真实浏览器完成新增/导入预览/编辑CAS/发布/详情/分页/失败提示/报告/复核操作，分别验证只读、管理和运行角色。当前来源为协议替身的结果不替代页面。
- EP-20：实测390/320px、键盘和焦点回收、弹窗Escape/未保存保护、连续切换、加载/错误/空状态及重复点击。TypeScript、ESLint和独立构建不能代替这些操作。
- EP-21：上线前保存当前备份、源码提交/摘要、迁移/镜像/依赖锁及build ID；确认旧恢复服务与独立测试端口归属，先停止准入，再按原发布脚本切换。085及080～084依赖分别核实，不盲目覆盖生产。
- EP-22：上线后实际登录、原会话和新评测入口烟测，默认未准入任务继续503；真实驱动启动后再逐项核验领取、撤权、取消、报告和资源回收。失败保留证据与回退信息，不把准备完成标为deployed。

## 全方案仍需独立完成

A20余下正式业务样本、B100个不同任务及三次独立重复、真实持久执行驱动/逐效果权限桥、CI故障门禁和持续评测按原方案验证。元数据CRUD、替身进程、题集条数或工程测试数量都不能代替这些验收；实际供应商模型质量仍按用户要求留为未测。
