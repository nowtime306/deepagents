# A20 剩余评测需求补齐

日期：2026-11-04。依据原 AE 需求、测试计划与固定题集的产品核对；不是新增任务验收或放宽原断言。4 个案例的既有限定验收保持原提交/报告，其他 16 个案例仍须逐批实现、审查、工程测试和隔离实测。

## 当前批次

- A01：旧 Agent 发布版不变，维护后的模型修订必须实际用于原 Ask 与定时发生的 Ask。真实工具创建 disabled 草稿、显式启用、真实 scheduler/worker 发生一次；不能止于草稿或由驱动直接创建自动任务。全案例计入两根调用、Token 和调度，通知为空。
- W02：原 Agent 修复、下载字节/源码差异、独立保护测试三者一致。第二个真实 leased Work 验证任务使用独立 Coding 环境；原错误源码至少失败一项，修复后三项通过。比较器不可改写，生成的编译/执行进程不能借控制接口提权；真实权限、网络限制和 JDK 探针必须另验。
- W03：上传真实修订、唯一固定命令、审批前完整 counter0 与零回执；正式拒绝后同 root 恢复，counter0/回执0/决定 reject 可重算。
- W04：在 WAITING 时真实重建消费者，同 checkpoint/root 恢复；批准后 counter1/回执1，已确认决定的显式重复不产生增量。普通续跑不代替消费者重建，也不能称作 OS 进程重启。

## 后续 Ask

- A03：真实文档/分块修订与索引就绪，最终引用须对应本次检索和原文；错误 ID、旧修订或不存在的 quote 均失败。索引 embedding、查询 embedding 和 Ask 一起计费，不能只验证检索命中。
- A04：实际查询完成但资料不支持问题时，准确拒答且无虚构来源；检索不可用不能伪称无证据。保留真实候选，不因答案拒答而删掉候选制造空结果。
- A05：修订空输入为明确非空任务，冻结新定义摘要。真实允许工具返回不可信内容，后续拒绝须有正式权限事件/代码及副作用0。不可把写工具谎标只读；“未暴露工具”与“实际实时授权拒绝”分开验证。仅使用合成材料和本机受控接收器。

## 后续 Work

- W05：实际成员委派、受控成员失败、父子角色/配置/用量及失败传播。主助手一句“完成”不能覆盖成员失败。
- W06：必须有真实父/子模型及运行中查询 embedding 的共享预算证据。当前单个模型两次 15900 Token 脚本不足以覆盖原需求；初始化索引另计，不能用它冒充运行内 embedding。耗尽后新 provider/tool 效果为0，未知不退款。
- W07：受控接收器已经写入但响应丢失，保留 UNKNOWN；重建后只查询同一根与接收器实际记录，不重新写入或换根重跑。需要明确核对路径才能解除未知，不能为回收强改状态。
- W08：除 `../` 外，还需真实软链和授权根外的合成私密 canary。禁止使用真实宿主密钥；合法成果精确 SAFE_INPUT，最新导出不得跟随链接或包含 canary。无法创建/观察链接属于缺覆盖，不算通过。

## 后续 Workflow

- F01：读取真实 current 指针再执行其版本，同时显式执行另一版；两版逻辑不同。需实际受控模型节点和维护后已用配置证据，零模型 transform 不能证明模型维护生效。初始化运行同样计量。
- F03：固定子版本受控失败，保留父/子节点前缀及失败位置；嵌套节点共享根，不虚构独立 child run。正式 502 只有与已持久 FAILED 运行相互印证才是已知业务失败；未知响应不重放。
- F05：修订/发布号按正式 API 二选一；固定代码、输入、路径、时限及摘要不可替换。草稿测试和发布后主运行各走真实审批/代码执行，各产生自己的 counter1，合计两次沙箱；不能将初始化成果算主结果。
- F06：三条声明分支的真实输入、输出及前缀事件齐全，汇合在全部分支后，结果按声明顺序。嵌套节点共享父预算，不因分支各自重置；参数化重复分支不另算任务或性能验证。
- F07：**保留原受控超时恢复/转支要求**。JSON 解析错误只能作为错误路由子场景，不能替代超时。先核实际编译器可安全路由的超时类型；必要时实现受限、可确定无写副作用的超时路由。外部写入结果或模型用量未知仍保持待核验，禁止通过 fallback 将未知改成成功。尚未实现的超时能力继续阻断 F07 完整验收，不删除必需 companion 获得通过。

## 统一交付规则

每个案例先冻结完整素材、初始化、必要子场景、观察字段和总预算；登记 ID 或 validator 名称不等于实现。各次重复新环境，业务 FAIL、故障控制识别、证据缺失和环境故障分开统计。独立事实封存/只读重算、原生用量、清理和 ready 消费使用同一合同。任何新增定义都保留历史摘要，不回填旧报告；案例数与初始化/子场景/重复次数分别计数。
