# 智能对话 SSE 实施与验收

## 当前范围

按用户最新澄清，本轮仅修改“智能对话”（Ask）。之前将任务工作台、工作流也纳入 SSE 属于范围误读，相关本轮改动撤回到开发前源码，保留原有运行、审批、节点单独测试等功能。其他管理页面的查询方式不变。

不恢复任何旧数据库或配置，不覆盖用户删除的工作流、知识库调整、账号或模型密钥。不提交或推送。旧扩展方案及测试证据留在 `.local/team-workspace/unified-sse`，不作为本次交付功能。

## 验收目标

1. 智能对话真实增量输出：沿用 `/api/v1/runs/{id}/events`，模型尚未生成完时界面已显示前面的文字；不把完整答案事后切片。
2. 同一对话连接传递运行状态、用量和诊断等关联信息；最终快照到达后正常结束。过程说明与最终答案的现有分组及操作栏规则保持。
3. 游标续传、重复事件去重、中文跨包解析、切换对话及取消、断线重连和权限撤销正确；断流不能被误判为运行成功。
4. 保留无新控制帧的旧协议兼容。新协议收到终态后继续读取最终快照与 `stream.end`，不能因提前 EOF 丢失末尾数据。
5. 真实 Next 生产代理下验证禁止缓存/缓冲/转换和结束前可见；断开连接不破坏数据库连接或导致后台退出。
6. 任务工作台、工作流恢复开发前接口及页面行为，无本轮新增 SSE 路由、异步 202 执行或节点增量契约。

## 实施与验证

1. 用本轮前已验证的源码备份逐文件比较，只撤回本轮非 Ask 修改；共享文件逐段检查。验证：基线摘要、差异审查及原有工作流/任务回归。
2. Ask 作者自验后独立代码审查，审过再交测试。验证：解析器、隔离数据库、受控本机模型、真实代理及浏览器。
3. 使用已有部署脚本完成当前状态备份、构建、重启和健康检查。验证：当前用户数据与密钥摘要、网页及后台就绪。

真实外部模型联调继续跳过。结果按实际测试批次分别记录，不将此前全域测试数量合并成 Ask 的验收数量；不承诺“绝对没有 bug”。
