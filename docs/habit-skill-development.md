# 平台习惯学习元技能开发计划

依据habit-skill-plan.md HSK-01～06，在onwer_agent开发，保留原数据/模型密钥/已完成工作流与Ask SSE，不提交推送。目标是平台闭环：显式启用并绑定元Skill→当前真实Ask用户偏好取证→三独立消息自动生成正规私有子Skill→智能体受控列表/读取与应用→纠正/停用/遗忘。

## 开发顺序

1. 元技能与有限六类偏好契约先冻结，验证SKILL格式与平台parse_skill。
2. 后端新迁移/服务/API/真实工具集成，生成确定性正文、严格来源和权限/版本/幂等；作者在隔离库验证，不额外启动模型提取任务。
3. 前端“能力中心→Skills→习惯学习”：一处启用/安装绑定、候选/生成列表、计数/版本、纠正/启停/遗忘/重新学习、来源原会话及生成资源查看；默认关闭，中文、读权限不显示写操作。
4. 作者自验→独立代码审查→修复复审→独立QA（33用例分层），实际受控agent工具调用/生成记录和下一轮读取，不以模型自称记住代替。
5. 既有部署脚本备份当前状态→迁移→生产构建/重启→健康与当前数据/主密钥核对，精确清理隔离资源。

## 前端/接口约定

GET/PUT /capabilities/habits 设置与列表；POST /install安装并合并绑定通用助手；preferences/{id} correct与toggle/relearn带revision，DELETE带revision查询。证据接口仅有权限返回来源ID/时间，不复制原文；通过父组件回调打开已授权原会话，不伪造不存在的跳转地址。生成Skill用原资源预览接口查看。

新页面组件独立封装，不改变记忆候选审阅规则；当前通用助手绑定可用，自定义Agent仍按原资源发布流程绑定元Skill。关闭学习同时关闭元库自动读取；用户手工绑定的普通子Skill仍按旧授权/版本读取，单独停用与遗忘保留撤权保护。工具读法不会改写已发布agent快照或旧上下文。

有限习惯：language、output_format、detail_level、docs_first、review_before_test、management_layout。未知、项目特定/本次限定、引用资料、临时授权/额度到期、凭据不自动生成。未来任意自由指令/脚本生成不在本轮。

结果以真实执行记录为准；此文件是实施计划，不是完成声明。
