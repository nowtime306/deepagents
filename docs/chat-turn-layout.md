# 对话按轮分组布局（2026-11-02）

按用户提供的布局示例，将同轮公开的过程说明、工具调用和最终回答分开；补齐此前只隐藏中间消息按钮的处理。只改变前端，不修改历史消息或模型上下文，不展示模型未提供的隐藏推理。

## 已实现

- 用户提问单独靠右显示。同轮过程归入可展开的“用时…”区域；生成中默认展开，完成后默认收起。
- 最终回答独立显示，复制、评价、分支保留在最终回答下；过程中的公开说明和工具记录没有回答操作栏。
- 用时读取既有运行记录的开始/结束时间。记录不可用时显示“处理过程”，不编造耗时；失败、取消、等待执行有相应状态。
- SSE收到已提交的助手/工具消息后，合并读取最新消息记录，实时更新过程；终态重新读取历史。迟到的中间请求不能覆盖最终回答，切换会话后也不更新旧视图。
- 每轮Token统计保留，运行诊断放到过程区域；需要用户操作的自动任务卡片仍在正文可见，避免收起后找不到启用入口。
- 兼容多轮、旧消息、刷新和390px窄屏。没有新增依赖、数据库变更或真实模型请求，改动保留在onwer_agent，未提交推送。
