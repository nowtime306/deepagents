# 工作台UI调整计划（2026-11-01）

采用OpenClaw Control UI的浅色方向。实际核对GitHub页面：OpenClaw约393.6k Star、Hermes Agent约259.2k、Dify约160.1k；在本次比较的Agent项目中OpenClaw最高，不把动态Star数当作永久全站排名。

参考：[OpenClaw仓库](https://github.com/openclaw/openclaw)、[Control UI说明](https://docs.openclaw.ai/web/control-ui)、[官方浅色主题](https://github.com/openclaw/openclaw/blob/main/ui/src/styles/base.css)。独立编写本平台布局和样式，不复制品牌、图标或整套界面代码。

## 调整范围

1. 统一中文系统无衬线字体、暖灰背景、白色面板和红色强调色，保持可见键盘焦点；模型/账号/能力等管理页同步统一按钮、字段和卡片。
2. 导航按工作空间、能力配置、平台管理分组；保留现有功能权限过滤和收起/手机菜单行为。使用单一侧栏滚动区，账号操作固定底部，避免菜单和历史争抢滚动空间。
3. 运营页增加明确页头、用量指标和区块快捷入口；模型调用显示模型名称，审计采用紧凑表格及独立滚动区，长编号和路径不再主导视觉。保留原查询、价格保存、审计分页及所有真实状态。
4. 页面不改业务权限、数据库或密钥；数据不因换肤重新创建。真实模型和外部服务仍暂缓调用，不提交推送。

## 验证标准

类型检查、修改页面静态检查和生产构建；实际Chrome核对运营/设置/账号/对话等页面、导航收起与分组、390px布局和长表格。回归现有主要页面行为，不用静态截图替代保存、授权和刷新检查。原生Git/浏览器专用测试需要样本时单独准备和按记录清理；UI修改不重复宣称新的后端全量结果。
