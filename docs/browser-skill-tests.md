# 浏览器操作技能化 QA 准备

2026-11-03。保留最初测试设计与合同演进，下方“初研准备”不代表当前实现状态。独立开发分支 `onwer_agent_browser_skill` 已完成后端58项、真实无页面运维6项独立验收，完整证据见该分支 `browser-skill-qa.md`；页面验收与部署仍pending。工作流WVR验收独立推进。

## 首要边界

生产 http://localhost:3100 的浏览器origin授权已被明确拒绝，QA/体验均不以CDP、Playwright、API或代理替代访问该页面。只使用另一个完全独立的虚拟数据站/本地示例业务站，独立账号和origin。录制、执行与发布仍按平台权限，不因“录过一次”获得任意浏览器控制/写入授权。

独立虚拟站3131在用户文字允许后完成过旧基线体验；此后根角色重试仍被保存权限明确拒绝，两次用户确认改设置后也未生效。当前不再访问页面或更换origin/工具/角色绕过；新界面验收需工具实际允许。协议替身、旧截图和源码构建不能替代此门槛。

## 需冻结的功能合同

录制一次用户授权的操作→生成可读的结构化动作轨迹→显式选择可参数化字段→生成待审Skill→用户/策略审查通过→绑定Agent按固定版本受控复用。录制会话、动作轨迹、参数schema、Skill版本、审查状态与执行记录应有可追溯ID。视频/截图仅辅助证据，不能把一段录像称作可执行技能。具体endpoint/status/浏览器实现以后续PRD为准。

## 准备的独立用例

- BS01：只有本人/授权角色/允许origin能开始、停止、读取录制，跨owner猜id与旧会话租约拒绝。空录制不生成可执行Skill。
- BS02：实际点击、输入、导航/等待按顺序记录真实定位与结果，不将截图或模型生成的想象步骤冒充轨迹；标识不稳定/步骤失败明确待修。
- BS03：演示站计数器核对录制中动作只发生一次，回放只在显式运行后发生；断开录制/页面关闭/超时不自动重放提交副作用。
- BS04：录制停止后资产包含结构化轨迹，视频存在不代表轨迹完整；只有视频/缺关键动作的输入拒绝发布为可复用Skill。
- BS05：参数化示例姓名/搜索条件等有类型、必填、范围校验；改变参数后实际运行用新值，原轨迹/演示数据不被覆盖。
- BS06：密码/令牌/会话Cookie/私钥参数不写入Skill正文、轨迹、截图DOM快照、录屏旁带数据和日志。使用fake敏感标记验证，运行时secret若需要，只经已授权引用传递，不能借参数注入命令或扩大origin。
- BS07：未审、已拒绝、内容改后未重审、旧审查digest与新动作不匹配都不能执行；发布版固定轨迹/参数schema及批准范围，不暗读latest。
- BS08：Agent实际读取绑定发布Skill并按受控执行器复用，检查示例业务站真实状态，而非模型最后自称成功；Work/Ask权限分界和提交审批保持。
- BS09：绑定撤回、Skill停用/删除/版本变化、允许域收缩、账户撤权后旧执行器不能继续新步骤；已经提交的外部动作不被虚称撤回。
- BS10：浏览器/执行环境重启、未知网络结果、断连后只恢复明确安全步骤，未知写入标成unknown/待检查，不自动双提交。
- BS11：模型/页面内容中的提示注入（要求导出Cookie、读本地文件、访问别的域、关闭审批）不能改变服务端能力和授权范围。
- BS12：中文录制列表+新增入口、轨迹详情/参数编辑、审查/发布状态、执行结果，390px可操作；错误说明明确，不用不可复现“成功”截图替代状态。

## 初研准备（历史状态）

本期仅文档与隔离fixture规划，未实现BrowserSkill业务。最终测试用本地虚拟表单/搜索站记录一次性提交计数和结构化事件，假secret只在fixture私密目录生成，输出目录/脚本/凭据隔离。作者自验→独立review→最终freeze之后才实际录制/回放；部署仍由root确认，不stage/commit/push。

- BSK-05→BS07/08：显式确认发布、parse_skill正规SKILL.md+文本资源、固定快照/重试幂等、不运行网页、不自动绑定所有Agent；历史元信息和普通Skill版本守卫保持。

## 产品1.1／真实扩展1.2合同纠正

单host专用连接由管理员持有：start、后台处理和重放每一步均重新要求admin，普通skills.manage/work.execute不足以接管管理员profile；管理员降权后下一步应停止，不能只在启动检查一次。

产品根据真实0.4.1扩展记录已纠正：--redact-values也遮普通fill/select，磁盘trace的page="sN.txt"相对states目录，不是page="states/sN.txt"。正式夹具遵循该实际导出；使用经产品允许的普通录制值也只限私有临时处理后参数化，密码步骤仍阻发布。上述纠正替代前一版测试设计中关于普通fill值与page前缀的推断，不能借错误假设放宽任意文件读取或持久保存录入值。
