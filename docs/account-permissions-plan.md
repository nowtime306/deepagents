## 产品规则

- 注册默认“提交后审核”；管理员可选择开放注册、审核注册或关闭注册。有效邀请码可在关闭注册时使用，邀请码绑定预设角色、一次使用、明确有效期。注册请求不能指定管理员、审批状态或任意权限。
- 原平台管理员完整保留。平台预设管理员、成员、只读角色；管理员可创建自定义功能角色并分配给账号。平台管理员专属的账号/凭证管理与组织内部 owner/admin/editor/viewer 分离。自定义角色不通过勾选功能权限获得平台管理员身份。
- 功能权限覆盖对话读取/管理/运行、任务读取/管理/执行、Agent、知识库、技能、MCP 使用、工作流、长期记忆、媒体和组织入口。后端入口强制校验，私有资源归属检查继续有效；运行期间撤权和停用也须停止后续操作。
- 新注册账号可等待审批，管理员审核、分配角色、停用和恢复。禁用/角色变更撤销旧登录会话，禁用不删除用户数据。串行化管理变更并保护最后一个可用平台管理员。
- 本人改密需原密码，新密码至少 12 字符；改密撤销全部旧会话。管理员重置生成一次性显示的临时密码，要求下次登录先修改，不能读取旧密码。临时密码不进入审计和日志。
- 登录会话列表只显示非凭证标识、创建/过期信息和当前会话标记；本人/管理员可撤销。旧会话没有记录创建时间则显示未知。
- 登录、注册限流并使用 scrypt；邀请只保存摘要。注册、改密、审批和权限编辑均有中文表单、校验、成功/错误状态。页面使用现有 ChatGPT 风格中性配色与可访问弹窗。

## 实施顺序与验证

1. 数据迁移与认证服务 → 验证旧账号仍能登录、原 admin 不被降级；注册伪造字段和重复用户名被拒绝。
2. 后端角色与权限 → 验证未登录、未审核、停用、只读、自定义角色、越权修改、跨账号资源、最后管理员和并发管理变更。
3. 注册/管理/本人设置页面 → 真实浏览器完成注册→审核→分配权限→登录→改密→旧会话撤销；邀请码过期/复用和重置密码流程。
4. 对话/任务/工作流运行期授权 → 使用本机协议替身验证撤权停止新调用，外部请求结果未知不自动重放。
5. 完整后端回归、页面回归、生产构建、迁移备份/恢复和重启 → 更新验收证据及剩余阶段状态。

## 外部依赖边界

本轮注册使用本地账号，不需要邮箱、短信或第三方凭证。邮箱找回、企业 SSO/MFA、业务 OAuth 仍按实际接入能力独立开发/验证；不会用一个不可工作的“发送验证码”按钮代替实现。真实外部模型/搜索联调继续遵守 integration-checklist.md，未接入不写通过。
