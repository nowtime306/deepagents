# 主动任务、批量执行与通知实施计划

2026-11-01，onwer_agent。承接阶段 3 的持久批量任务和阶段 4 主动任务；不变更本聊天已有 Codex 自动任务或独立重置卡任务。默认关闭新建调度，真实外部模型与真实消息渠道继续等待用户接入授权。

## 调度与执行边界

- 使用本人已发布 Agent 版本，固定指令、模型修订、资源与团队快照。支持 Ask 只读任务、Work 任务；Work 的命令、删除与外部写操作继续审批，文件变化限定任务工作区。
- 一次性、固定间隔（至少一分钟）、五字段 Cron；明确 IANA 时区并预览 UTC/本地时间。支持整数、列表、范围、步长，日/月/星期取常见 Cron 的日与星期 OR 规则。不存在的夏令时点跳过，重复本地时刻只取第一次；不支持的语法明确拒绝。
- 增加公开签名事件触发，密钥一次显示、服务端加密；校验时间戳和原始请求签名，事件 ID 与内容摘要防重放/参数复用。事件内容作为不可信数据，不改变已发布 Agent 的权限、目标模型或预算。
- 当前 Windows 已安装 tzdata 2026.6；使用标准库 zoneinfo，显式声明 Windows 时区数据依赖，不引入另一套调度运行时。
- 触发记录与 Ask/Work 入队同一事务，按调度 ID 和计划时刻唯一；多调度器竞争用行锁/幂等约束。重启后按“跳过错过”或“补一次”策略处理，禁止无限补跑。
- 默认跳过上一次仍忙的执行；可选择有上限的排队。每账号最多两个主动执行在途，人工任务优先。暂停/删除停止未来触发并取消在途请求；编辑只影响未来执行。删除保留已发生任务的历史。
- 执行时重新检查账号、主动任务执行权限、目标功能、来源和资源授权；摘要等隐藏模型调用也必须经过同样权限和账本预占。未知结果不自动重放。

## 持久批量任务

- 一批最多二十个独立目标，使用同一发布版本；每项独立会话/任务，进度和结果可追溯。批次可暂停、继续剩余项与取消，已发生请求和成果不伪造撤销。
- 同时最多两项在途，复用已有 Ask/Work 租约。单项与批次共享调用/Token 预算，数据库原子预占，角色与根调用均计入一次；未知用量保守占用预留。
- 默认失败暂停；结果未知必须核对后显式继续剩余项，不重试旧请求。首版批次不混用工作流工具，避免跨编排预算边界被静默绕过。

## 通知与通道

- 先提供本人通知、未读/已读、任务链接与历史，默认仅在完成、失败、需审批/核对时通知；同一事件去重，已读不因重复轮询变回未读。
- 补签名 Webhook 及经官方协议核实的飞书、企微、Slack 群机器人；通道绑定本人账号和目标地址，只有本人可选用。Webhook URL 和签名密钥加密，不出现在审计、模型上下文、错误或网络日志中。
- 仅发送任务名称、状态、时间及目标标识，默认不发送问题、输出或文档。校验目的地址、固定解析结果、防重定向；本机接收器仅供管理员明确允许的私网通道测试。
- 投递有持久状态和租约；结果未知不自动重发，人工重发明确提示可能重复。通道配置变更后不能把旧通知静默改投新地址。真实渠道效果需用户确认目标后再验收，不擅自给真实群发测试消息。
- 新增主动任务读取/管理/执行、通知读取/配置权限；预设成员添加新能力、只读角色只添加读取，自定义角色保持原权限不自动扩权。

## 顺序和验证

1. 时区/Cron 工具及迁移 → UTC/上海、夏令时缺失/重复、闰日、日/星期 OR、无效语法、预算和权限边界。
2. 调度/批次服务 → 多实例认领、断点前后重启、错过/忙碌策略、撤权、暂停、重复事件、并行预占和未知结果不重放。
3. 通知/投递 → 私有账号隔离、已读去重、URL/密钥脱敏、签名篡改、网络超时/拒绝、配置撤销与人工重发；真实本机接收器确认协议。
4. 中文页面 → 新建/编辑/预览/启停、批量执行/取消、通知跳转、桌面与窄屏；完整回归和生产构建通过后再开放入口。
5. 备份、迁移、重启和记录 → 保留原模型/密钥/用户数据，更新验收文档与待用户接入清单；不提交推送。
