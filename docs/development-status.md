## 已实现

- `apps/web`：导入 Agent Chat UI 并保留许可证，使用其 Markdown、代码高亮和基础组件；中文登录、主导航、会话列表、创建、重命名、删除、模型选择、流式消息、停止生成、错误与空状态。
- 桌面和手机布局，手机侧栏可打开历史和退出登录；未实现模式明确显示“待开放”。
- `services/api`：FastAPI、服务端模型配置、独立 Ask 图、中文错误结构、可信会话认证和资源归属校验。
- PostgreSQL 业务迁移、真实数据库 Checkpointer、消息持久化、按运行递增的事件序号、SSE 重放和取消状态。
- 取消时保留已输出的部分回答；取消请求不会被稍后的成功状态覆盖。
- Ask 短任务单进程保护、重启后未完成运行明确失败、已保存对话和检查点可继续使用。
- 独立 Docker Compose 数据库、随机本机密码、首次管理员引导、Windows 启动脚本和本地说明。
- 原通用 LangGraph API 透传路由已移除；前端只使用认证平台 API，不接收后台管理密钥。
- 参考 Nexent 提前实现中文“设置 → 模型管理”：添加、编辑、启停、默认模型、连接测试、删除，以及可选输出上限和温度参数；配置保存在数据库，保存立即生效。
- 模型密钥加密保存，管理接口只返回“已配置”标志；编辑留空保留、明确勾选后清除；管理员才能管理，普通用户只读取启用模型列表。模型配置不再从 `.env` 读取。
- 中文能力中心：私有知识库、文档上传/删除/重建索引、中文关键词检索、检索来源；页面配置 Embedding 模型后使用本地持久化 Qdrant 混合检索，失败时保留关键词检索。
- MCP 页面配置、加密凭证、Streamable HTTP 连接测试与发现、工具参数查看、只读工具启停；官方 MCP SDK 协议调用已接入对话。
- Skills 支持 SKILL.md/ZIP 导入、同名版本递增、启停/删除、资源预览；通过官方 Skills/Filesystem Middleware 按需读取虚拟资源，阻止访问宿主文件和执行脚本。
- 当前用户的知识库、MCP、Skills 可绑定到通用助手，每次运行按账号重新加载和授权；失效资源从可用绑定中移除。知识库/Skills 归属校验、MCP 管理员权限、运行时绑定撤销检查均在服务端执行。
- 模型管理扩展至截图对应的十类用途、十三个服务商选项，支持名称/类型/服务商筛选、地址预填、协议选择；通过官方 LangChain 适配接入 Anthropic 原生 Messages。未接入实际业务的模型类型仍可保存配置，页面明确标记检测和业务待接入。见 [model-types.md](model-types.md)。
