# 知识库体验改版实施文档

2026-11-02，依据产品需求 [v1.0 / KB-01～KB-12](knowledge-center-requirements.md) 与独立 [UI Demo](../apps/web/public/demos/knowledge-center.html) 实施。产品先冻结需求，开发实现，测试按需求验收，再使用运维交付脚本部署。限定于知识库前端，不新增后端能力、依赖或数据库迁移；保留现有资源、密钥、MCP、Skills、记忆及未提交改动。

## 实施与需求映射

- KB-01/10/11：`capability-center.tsx` 保留创建对话框与绑定操作，知识库列表增加名称/描述筛选、真实数量、加载/失败重试/无匹配反馈。按当前页和已有权限加载资源，知识库只读用户不被无关MCP/Skills接口阻断；权限由平台现有账号状态透传，服务端校验不变。
- KB-02/03/07/12：将原长详情页抽出为 `knowledge-workspace.tsx`，默认文档页，提供文档、检索测试、配置、处理记录、评测、图片资料六个语义页签；OCR为独立入口。文档表保留名称、大小、分块、修订与实际向量状态，支持本地搜索和状态筛选。页签在窄屏内部滚动，表格容器限制横向溢出。
- KB-04/06：使用Radix上传弹窗，明确单文件类型/4MB、所选文件、提交和结果，客户端先校验；导入只提交一次，未知结果提示先刷新核对。沿用现有替换、重索引和具名删除确认；操作失败保留原列表，成功后读取服务端数据更新。
- KB-05：复用 `DocumentRevisionActions` 的真实分块与修订弹窗及分页；新库挂载新详情，文档列表读取使用取消/有效标记阻止迟到写入，检索失败清理旧结果。切页保留本库搜索，切库重置。
- KB-08/09：`knowledge-processing.tsx` 增加设置/记录两个视图，避免日常页挂载轮询；原分块、OCR、评测、图片知识组件仅在进入对应区域时挂载。保留重排即时保存与关键词策略表单，显示关键词检索和向量配置边界；不提供不支持的向量模型切换。

## 接口与数据边界

沿用 `/capabilities/knowledge`、`/{id}/documents`、`/search`、`/rerank`、`/retrieval`、`/processing`、`/operations`、文档修订/分块/重索引，以及现有OCR、评测和图片接口。无新统计字段，所有大小/分块/索引状态来自服务端，不编造任务队列或进度。绑定仍提交完整现有bindings，只调整当前库ID；权限分别遵循knowledge.read/manage/search、chat.manage及原OCR/图片权限。

## 验证与部署

测试文档由测试角色按KB编号编写；新增页面接口替身测试覆盖状态和权限，原 `knowledge-operations.spec.ts`、`platform.spec.ts` 的知识/MCP/Skills真实本机回归按新导航适配，业务断言保留。运行TypeScript、增量ESLint、生产构建和Chrome检查。后端接口不变，不以旧全量后端测试数字充当本轮新结果。

运维提供 `knowledge-center-deployment.md` 与受控部署脚本；测试完成后部署并复验。失败时使用其记录的构建备份恢复，不触碰用户数据目录与主密钥。真实外部模型/OCR质量联调继续跳过，以本机协议替身验收，并明确记录此边界。
