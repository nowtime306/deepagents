# 知识库、MCP、Skills 开发与验收

> 最新实际支持范围及验证以 [implementation-verification.md](implementation-verification.md) 为准。下文保留首版说明，以下明确更新当前使用方式。

本次在 `onwer_agent` 实现可使用的中文能力中心，并接入现有 Ask。沿用模型页面配置、服务端授权和数据库存储，不要求用户编辑能力配置文件。

## 实施顺序

1. 知识库：创建、上传 TXT/Markdown/PDF/DOCX、文档状态/删除、检索测试和来源；默认关键词检索可独立使用，配置 Embedding 后启用 Qdrant 混合检索。验证真实数据库、文档解析、跨库授权与删除后不再召回。
2. MCP：页面配置 Streamable HTTP 服务、加密凭证、连接测试、工具发现和启用。首版仅执行明确声明只读且经管理员启用的工具；写工具等待审批执行能力，不允许在平台宿主机运行任意 stdio 命令。验证 SDK 协议、发现和真实工具调用，检查无凭证回显。
3. Skills：上传 SKILL.md 或 ZIP、校验元数据和归档路径、资源预览、版本和启停；通过官方 Skills/Filesystem Middleware 按需读取已授权资源。验证正常加载、路径穿越/符号链接拒绝和运行时读取。脚本随包保存但在沙箱接入前不在宿主执行。
4. Agent 绑定：当前通用助手按当前用户保存知识库、MCP 和 Skill 选择；每次运行重新授权，旧选择失效时拒绝越权。前端展示绑定和工具结果。

## 权限和完成标准

知识库和 Skills 按用户隔离；MCP 由管理员配置，只有明确启用且只读的工具可绑定。页面有中文错误、空状态、加载状态和删除确认。数据库保存元数据及解析资源，模型/MCP 密钥加密。对上传大小、解压大小、文件数量、工具执行时间和检索结果数量设限。

真实 LLM 联调仍按用户要求跳过；使用确定性模型与真实数据库/协议服务验证绑定、检索、工具调用和技能加载，不将这些测试描述为真实模型质量验收。混合检索须配置真实 Embedding 才能验证效果，未配置时页面明确显示关键词模式。

## 使用方式

### 知识库

1. 打开“能力中心 → 知识库”，新建知识库。未选择 Embedding 时可直接使用中文关键词检索。
2. 上传 TXT、Markdown、PDF、DOCX 或 XLSX，单文件最大 4 MB。PDF 最多 100 页；扫描件需先做 OCR，本次不包含 OCR。
3. 在文档页面输入问题进行检索测试，查看片段、文档名、页码/位置与引用 ID。可删除文档；Embedding 索引失败时可重试。
4. 勾选“绑定到通用助手”，后续对话可调用 `search_knowledge`。是否调用由所选聊天模型决定，需要模型支持工具调用。
5. 如需向量检索，由管理员在“设置 → 模型管理”添加类型为 Embedding 的 OpenAI 兼容模型，再在新建知识库时选择。实际请求使用 `/embeddings`，结果写入本地 Qdrant，与关键词结果融合。创建后的知识库暂不支持切换 Embedding，需新建库并重新上传。

向量存储采用本机嵌入式 Qdrant，无需额外服务，适用于当前单实例开发。解析内容和索引属于平台数据，删除操作由数据库归属校验约束；删除后的文档不会再次召回。当前已支持重排与 Excel，OCR 尚未接入；Excel 公式仅保存为文本，不执行计算。

### MCP 工具

1. 管理员打开“MCP 工具 → 添加 MCP”，填写 Streamable HTTP 地址及可选 Bearer Token；访问本地或内网地址时明确勾选允许内网。
2. 点击“测试并发现工具”，查看工具说明与参数。工具需经管理员明确启用。只读工具可用于对话和工作流；写工具需管理员确认启用，且只允许平台管理员在 Work 中逐次审批执行。
3. 用户勾选绑定，下一次发送消息时加载工具；每次调用重新检查服务启停、绑定和工具权限。
4. 编辑 Token 留空保留已有值，勾选清除才删除。凭证不回传浏览器；修改配置后工具授权清空，需要重新发现和启用。

当前不支持 stdio、SSE 旧传输和 OAuth 登录流程；MCP 写工具已接入 Work 审批及操作记录。MCP 工具的只读声明来自服务端，管理员应只接入可信服务。平台、数据库和容器管理端口禁止作为 MCP 目标。

### Skills 技能

导入 `SKILL.md` 或包含它的 ZIP。文件使用 UTF-8，必须包含以下 YAML 头部：

```markdown
---
name: report-helper
description: 根据用户资料编写中文报告
---

先确认资料中的事实，再按结论、依据和后续行动组织报告。
需要时读取 references/ 中的参考文档。
```

技能名称使用小写字母、数字和连字符，最长 64 字符。ZIP 资源需位于同一技能根目录，拒绝路径穿越、符号链接、二进制内容和超限归档；最多 100 文件，展开总量 2 MB，单文件 512 KB。同账号同名导入会替换当前资源并递增版本，暂未实现历史版本回滚。

勾选绑定后，官方 Skills Middleware 把技能元数据加入模型上下文，模型按需读取 `/skills/<name>/SKILL.md` 和文本资源。资源来自受限虚拟文件系统，无法读写宿主目录。Ask 只读取技能资源；Work 可用 copy_skill_resource 将已授权版本的脚本复制到任务工作区，再通过 execute 命令审批在任务环境中执行。宿主机不运行技能脚本。

后端 27 项测试、浏览器 4 项测试、TypeScript、Ruff 和 Next.js 生产构建通过。知识库使用真实 PostgreSQL/Qdrant，向量测试使用确定性向量；MCP 使用官方 SDK 客户端与服务端完成 HTTP 协议往返；Skills 已验证在图内通过原生中间件读取。真实外部模型和外部 MCP 服务的环境联调仍需实际服务配置，未用测试替身代替该项验收。
