# 让知行智能体学习可复用习惯

入口：能力中心 → Skills 技能 → 习惯学习。新账号默认关闭。

## 开始使用

1. 开启习惯学习。具备资源管理和助手配置权限时，平台安装 `habit-skill-builder` 元技能并追加到通用助手，保留原知识库、MCP、记忆和手工技能配置。
2. 在新运行中明确表达长期偏好，例如“以后回复默认用中文”。通用助手的模型需要支持工具调用，并实际调用学习工具；页面只展示服务端已确认的证据，不根据回答中的“记住了”判断成功。
3. 三条不同真实用户消息提出同类同值偏好后，平台自动创建本人私有 Skill。无需重复绑定每个子技能；获准使用元技能的智能体可在适用任务中列出、读取它。
4. 独立智能体需在智能体资源配置中选择同一元技能，按原流程发布新版本。旧已发布资源快照不会后台改写。Work 可查用已生成的习惯，不从任务描述采集新证据。

目前支持六类：中文/英文回复，Markdown/纯文本/JSON格式，简洁/详细内容，开发前先整理文档，代码审查后交独立测试，管理页面采用列表与新增入口。不支持的习惯不会强行归类，也不生成脚本或自动授予执行权限。

## 查看与纠正

列表可查看有效证据数量、状态、生成版本、来源会话及Skill正文。你可以直接采纳或纠正有限值，明确人工确认后不必等三条证据。新运行按新资源使用；已经送入模型的旧正文无法从其上下文撤回。

- 关闭总开关：停止新学习和元库自动读取。已经手工单独绑定的子技能仍按原资源授权管理。
- 暂停单条：不新增证据、不允许元库使用。恢复保留原有效来源，只接收恢复后的新消息；候选恢复后仍需达三条门槛。
- 遗忘：清除关联的历史派生技能内容和学习证据，撤销后续读取；保留不含原文的抑制记录，旧消息不会重放再生。不删除原聊天或手工技能。
- 重新学习：明确解除该条抑制，只统计操作之后的新真实消息。

来源删除后，有效证据不足三条且未经人工确认的自动技能不可再使用。页面会提示来源不足；可以纠正采纳，或重新学习。

## 使用边界

只从开启后、获准当前Ask运行的真实原始用户消息采集；不回扫历史，不追踪键鼠，不读取别的账号，不把分支复制、引用、附件、临时授权或项目限定当成通用习惯。使用已有技能不增加证据。模型误提议会返回明确拒绝结果，普通问答可继续；不会把失败说成学习成功。

生成采用平台固定模板，没有额外后台模型提取任务；当前模型工具交互用量仍记录在原对话。真实供应商是否主动提议、如何遵循技能，需要使用你配置的支持工具调用模型验证；本轮开发验证使用本地受控模型，不调用真实外部模型。
