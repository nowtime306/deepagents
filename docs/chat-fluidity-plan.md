# 对话交互流畅度优化

日期：2026-11-02。范围：现有中文智能对话页面，保留数据和既有功能，不变更模型服务。

1. 滚动跟随：仅在用户停留底部时跟随新内容；向上阅读时保持位置，提供“回到最新消息”。加载更早消息时保留当前阅读位置。通过长回复流式输出和历史分页页面测试验证。
2. 输入与渲染：按浏览器绘制节奏合并流式片段，缓存未变更的历史消息渲染。输入框即时伸缩，保留 Enter 发送、Shift+Enter 换行，中文输入法确认不发送。通过键盘、长输入和流式输出并行操作验证。
3. 会话切换：加载中显示明确占位，清空上个会话的草稿和附件并暂禁发送；新建对话清空旧草稿。延迟响应不能覆盖新会话。通过交错返回的页面测试验证。
4. 验收：执行相关聊天回归、类型检查与生产构建，部署后验证桌面和移动视口。真实外部模型联调继续跳过。

## 验证记录

- 已移除每次片段/用量更新触发的平滑滚动，改为底部跟随；上翻后暂停，点击箭头回到底部。内容及窗口尺寸变化保持跟随，展开过程主动暂停跟随，加载历史保留阅读位置。
- 流式片段按绘制帧合并；未变化的消息和轮次缓存渲染，输入草稿不再触发整段历史 Markdown 重算。输入框在绘制前调整高度，保留 180px 上限、Shift+Enter 换行，中文组合输入及 keyCode 229 不触发发送。
