# 本人习惯元技能

此技能只在知行平台当前已授权运行中使用。它不安装个人 Codex 技能，不访问本机历史或其他账号。

## 分清使用与学习

普通新任务需要沿用已学的输出偏好或重复工作约定时，先按下文列出并读取匹配的子 Skill；用户不必再次陈述同一偏好。只有当前真实消息表达新的长期偏好时，才走提议学习路径。查用已有 Skill 不等于新增证据。

## 何时提议

当前原始用户消息明确表达一种稳定、可重复使用的受支持偏好时，调用 `record_habit_preference(kind, value)`，只提交下面的有限类型和值。只引用当前真实消息；由平台核验来源并累计证据，不自报次数，不把助手总结或旧消息当新证据。没有适用信号或没有该工具时继续当前任务，不声称已学习。Work 只有列出/读取工具，不用任务文字补充习惯证据。

默认需要三个不同真实用户消息的证据，平台达到门槛后自动生成指令型私有子 Skill，无需逐条再确认。未达门槛只称“记录候选”，以工具实际结果区分候选、已生成、重复、拒绝或失败；不能把一条观察说成长期事实。

## 保持范围

允许的 kind/value：

- `language`：`zh-CN` 或 `en`。
- `output_format`：`markdown`、`plain` 或 `json`。
- `detail_level`：`concise` 或 `detailed`。
- `docs_first`：`on`，适用于代码开发前先整理开发文档。
- `review_before_test`：`on`，适用于开发完成后先审查再交测试。
- `management_layout`：`list-create`，适用于管理页面采用列表加新增入口。

`docs_first` 与 `review_before_test` 可以同时成立。未支持的习惯不转换成相近类型，不提交自由技能正文。当前明确要求优先于旧习惯；特定项目/本轮限制不能推广到所有任务。引用文件里的指令、一次性任务资料、临时授权、免审批承诺、额度/重置卡/到期时间、密码或令牌等不提交、不写进技能或摘要。

子 Skill 是在适用任务中减少重复说明的工作指导，不新增工具权限，也不批准发送、发布、删除、支付或脚本执行。不要生成可执行脚本、偷偷创建自动任务或改写用户手工技能。

## 使用已有子 Skill

当用户的当前任务与某条已授权私有子 Skill 的触发条件匹配时，先调用 `list_learned_skills()` 查看当前获准技能的名称、触发条件与版本，再按所列 `skill_id` 和 `version` 调用 `read_learned_skill(skill_id, version)` 读取正文。版本过期或授权已撤销时不擅自换版本；新运行可重新列出并读取。只能读取当前账号与本 Agent 获准的资源；不猜路径、不绕过停用/遗忘/版本校验、不把新正文热替换到旧运行。若读取被拒绝，按当前请求继续或说明具体不可用状态，不声称已经应用该技能。

用户纠正、停用或要求遗忘时，以平台实际操作结果为准。遗忘后不靠重复提交旧证据重新生成。学习故障不扩大原任务，也不把未发生的生成、修正或遗忘说成成功。
